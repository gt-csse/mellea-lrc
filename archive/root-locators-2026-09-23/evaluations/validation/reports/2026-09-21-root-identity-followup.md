# Primary root identity follow-up, 2026-09-21

The latest complete 26-filing primary checkpoint admits 288 of 366 gold-correct roots, with one wrong admission. This is 78.69% admission recall and 99.65% admission precision across 440 labeled roots. Two labeled roots never reached identity. These are development metrics from saved checkpoints; no retrospective evidence cutoff was applied, so they are not a paper-ready evaluation.

The v43 change grounded each proposed source field in the source filing and each cited field in the quoted independent document. Its citation quote is matched at 90% edit-distance similarity with whitespace relaxation, highlighted at original document offsets, and read through a view that removes only verified PDF margin line numbers. A source-docket provenance sidecar blocks a later filing in the same litigation from corroborating itself. Three gold-correct reporter roots in filing 011 became resolved; three gold-wrong admissions from filings 008, 009, and 015 became deferred. One additional gold-correct wrong rejection became deferred, and one gold-wrong deferral became a rejection; those latter two decisions can vary with the model and are not attributed to the grounding change alone. The v43 replay reused v37 search candidates and did not retest search retrieval.

The v44 stage routes a resolved root's saved, grounded third-party citation to a still-deferred neighboring root when they share a citation location. The model receives the source citation and independent quote and makes a new field-by-field judgment for that root; it is not told about the grouping. Four gold-correct docket roots became resolved: 005-o21, 006-o74, 006-o75, and 011-o07. A fifth eligible root in 009 remained deferred because the saved quote did not supply its docket number. No new wrong admission occurred. This stage made no CourtListener or GovInfo request and wrote one resumable Document per filing.

The code also now defers an exact reporter result when its only conflicting court came from a linked docket, while using the opinion cluster's own court when available. A bounded body-context match for a reporter locator must preserve every printed digit, so a near-matching year cannot consume review evidence. A clean zero-hit docket body search now tries a second query using the parsed docket identifier with collapsed whitespace; both queries and failures are serialized. These changes have focused tests, but their corpus-level effect has not been measured because the fresh search pool was returning 429 during this run.

A bare appeals-court parenthetical can now use the state uniquely identified by an official reporter, using only courts-db records and declining ambiguous states. Reapplying the court reader to saved primary text changes two occurrences of `218 Ariz. 293` in filing 021 from the Arizona Supreme Court to the Arizona Court of Appeals and changes no other primary occurrence. This is a read-only analysis of saved text, not a new identity score.

All 26 v44 Documents are in `data/run-artifacts/44-primary-shared-body-review-v1/shared_body_evidence_review`. Exact occurrence-level changes are in `primary-v37-v43-comparison.json` and `primary-v43-v44-comparison.json`; the aggregate result is in `primary-v44-root-identity-score.json`. The retry runner now reuses clean documents when a prior run attached the same source-provenance sidecar in memory, and retries transient failures recorded inside secondary search attempts. A resumed date correction now round-trips through Document serialization.

The largest remaining measured limit is provider availability: 57 of the 79 missed gold-correct roots in v44 have a transient body-search or terminal body-fetch failure in their saved trace; 87 roots of any label have a recorded 429 in the v43 artifact. These are opportunities for retrieval, not predicted admissions. The other 22 missed correct roots have no recorded transient body failure. The residual wrong admission is 026-o33, where the filing spells *Suffolk* as *Suffock*; its exact reporter locator identifies the case, and a literal case-name veto would also reject legitimate name variants. The remaining wrong rejections include exact-reporter court/date issues whose latest code changes still need a full upstream replay.

The annotation review corrected 005-o07, *Walker v. Sauvinet*, from correct to wrong identity on its written year. The [official U.S. Reports entry](https://www.govinfo.gov/app/details/USREPORTS-92/USREPORTS-92-90) gives the decision and citation year as 1876 while identifying 1875 as the court term. The dataset protocol judges the written date at its stated precision, and the gold row now agrees with that rule. Both annotation sanity checks pass. The score artifacts above were regenerated after this correction.

A separate `review_full_reporter_exact_dates(Document)` stage now inspects linked opinion headers when a unique exact reporter match agrees on name and court but differs on year. It records the dated phrases and admits only an event that agrees with the cited date and any retrospective cutoff. The stage changed *Michelson* from deferred to resolved on the quote “Decided December 20, 1948” in the v49 corpus checkpoint. CourtListener cluster transport now preserves `other_dates`, which is pertinent to amended opinions. Four exact reporter roots in the saved primary run have date-only conflicts; two in filing 019 cite amended versions and require opinion-level evidence rather than a one-year tolerance.

## Completed provider replay and separate stage scores

The v47 replay used the same 26 metadata Documents as v43. It reused eight clean body results and reran the other 18 from the pre-search checkpoint. CourtListener search and opinion/RECAP fetches now both honor the selected `main` proxy pool; the previous body client silently fell back to an exhausted default pool. This routing fix did not remove main-pool throttling. The v47 trace records 187 search 429 events and 28 terminal fetch 429 failures, versus 113 search 429 events and 29 terminal fetch 429 failures in v43. A saved 429 may occur alongside other successful evidence, so these counts are limits on interpretation, not a count of caused misses. Of the 78 still-missed gold-correct roots in v49, 63 have at least one recorded transient body-search or fetch event.

The fresh body stage gained one gold-correct admission (`003`, `444 F. Supp. 3d 593`) and lost one (`015`, `No. 25-11030`) relative to v43. One gold-wrong `008` citation changed from `no_match` to a search deferral. The identical aggregate body score is therefore a net result, not an identical occurrence-level run. v48 independently admitted four gold-correct docket roots using a sibling's grounded citation evidence: `005`, `No. 07-cv-00630-DME-MEH`; `006`, `No. CIV 11-0107 JB/KBM`; `009`, `No. 20 Civ. 6835`; and `011`, `No. 2:04-CV-01304-RCJ`. v49 admitted `006`, `335 U.S. 469`, because its matched opinion says “Decided December 20, 1948.” The other three date-only reviews found no supporting header phrase; none had a fetch error. The date-review trace now round-trips through a serialized Document, including its nested `DateExploration` evidence.

One upstream extraction miss was checked separately without changing the narrow federal docket reader. Current generalized site hunting proposed the exact unprefixed, whitespace-damaged `4:25-cv-  00175` span in filing 022 and the model admitted it as a docket locator. The scoped artifact is `data/run-artifacts/50-primary-022-docket-site-scope.json`. This root is absent from the v49 score because v49 resumes an older extraction checkpoint. The other unreached root is a yearless Westlaw locator in filing 025; the current reporter site-hunting profile is disabled, and no special-case yearless Westlaw rule was added.

The 22 v44 missed correct roots without a recorded transient body error include six exact-reporter rejections, six body candidate sets over the review limit, five bounded hits without a usable independent citation, three grounded quotes that point to a different decision, and two extraction misses. The current code already addresses two reporter aliases, one state appellate-court reading, and quoted refinement of broad body searches, but those upstream changes still need a fresh extraction/identity run to measure. Three of the reporter rejections (`018-o01`, `022-o08`, `022-o17`) came from a wrong linked-docket court, while independent opinion text supports the stated court; the new exact-lookup code defers those conflicts for opinion-level verification. It does not automatically admit them, because a correct reporter locator cannot waive a wrong court field. Two `003` LEXIS annotations say their serial numbers were not independently verified, while the retrieved third-party quotes identify different decisions. Their gold labels require an annotation-protocol review or a verified LEXIS source before treating them as clear false negatives.
